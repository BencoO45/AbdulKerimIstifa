# Pétition satirique — GitHub Pages

Site statique HTML/CSS/JS. La participation est enregistrée uniquement dans le navigateur (localStorage), pas sur un serveur. Aucun compteur global.

## Publication
1. Créez un dépôt GitHub public, par exemple `petition-bardakci`.
2. Ajoutez `index.html` et `affiche.png` à la racine du dépôt.
3. Dans **Settings → Pages → Build and deployment**, sélectionnez **Deploy from a branch**, branche **main**, dossier **/(root)** puis **Save**.
4. Le site sera disponible à `https://VOTRE-PSEUDO.github.io/petition-bardakci/` après déploiement.

Pour une vraie collecte de signatures, un service backend et une politique de confidentialité adaptés sont nécessaires.
